Pengaturan Web App URL Google Sheets

Masukkan Link Web App dari Google Apps Script untuk mengirim data pesanan secara otomatis ke Google Spreadsheet kelas/bazar kamu.

Cara Menghubungkan ke Google Sheets:

  1. Buka Google Sheets baru.
  2. Klik menu **Ekstensi** > **Apps Script**.
  3. Hapus semua kode yang ada, lalu tempelkan (paste) kode Apps Script berikut:
function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = JSON.parse(e.postData.contents);
  
  if (sheet.getLastRow() === 0) {
    sheet.appendRow(["ID Pesanan", "Waktu", "Nama Pembeli", "Stand/Meja", "Detail Items", "Total Harga", "Catatan"]);
  }
  
  var itemsStr = data.items.map(function(i){ return i.nama + " (" + i.qty + "x)"; }).join(", ");
  sheet.appendRow([data.id, data.waktu, data.nama, data.meja, itemsStr, data.total, data.catatan || "-"]);
  
  return ContentService.createTextOutput(JSON.stringify({"result": "success"})).setMimeType(ContentService.MimeType.JSON);
}
  1. Klik tombol **Terapkan (Deploy)** > **Penerapan Baru (New Deployment)**.
  2. Pilih Jenis: **Aplikasi Web (Web App)**.
  3. Ubah "Akses" / "Who has access" menjadi: **Siapa Saja (Anyone)**.
  4. Klik **Terapkan**, izinkan akses, lalu **salin URL Web App** dan tempelkan pada kolom di atas!
